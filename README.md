# Week 1 – Web Development Portfolio

This project completes the Week 1 HTML & CSS fundamentals assignment.

## Included sections
- About
- Education
- Skills
- Contact

## Files
- `index.html` — webpage structure using semantic HTML tags (`header`, `nav`, `main`, `section`, `footer`)
- `style.css` — responsive layout, colours, cards, buttons, and mobile styling

## Run locally
Open `index.html` in a web browser. An internet connection is needed to load the profile avatar.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `style.css`, and this `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. Submit the live URL shown in Settings → Pages.

Replace any profile or contact details if you want to change them before publishing.
